# 董鑫｜视觉设计作品集

面向 2027 届校招的个人作品集网站，内容包括多端运营视觉、品牌设计、海报、插画、字体与实践经历。

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 部署

网站使用纯 HTML、CSS 与 JavaScript，不依赖构建步骤，可直接通过 GitHub Pages 从 `main` 分支根目录发布。站内资源均为相对路径，兼容 `https://xiny-02.github.io/Portfolio/`。

## 内容来源

网站文案与作品图片均整理自董鑫本人的简历和作品集。完整材料位于 `docs/`。
